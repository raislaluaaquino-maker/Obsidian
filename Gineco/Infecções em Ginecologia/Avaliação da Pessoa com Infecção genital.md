# Microbioma vaginal
→ ==Conteúdo vaginal==:
- Água;
- Eletrólitos, proteínas;
- Muco;
- Células (vaginais, cervicais, esfoliadas);
- Microbiota.
→==Espécies==:
- Microbiota:
	- Aeróbias: lactobacilos;
	- Anaeróbias:
		- Facultativas: gardenerella vaginalis;
		- Estritas: ureplasma urealyticum, mycoplasma hominis.
- Fungos: Candida sp.
>[!warning] A microbiota é dinâmica;
>- Questões genéticas;
>- Relacionadas a idade;
>- Status hormonal.

# Como Pesquisar o conteúdo vaginal:
- Anamnese:
	- Comportamento sexual;
	- Data da última menstruação;
	- Práticas de higiene vaginal;
	- Uso de medicamentos tópicos ou sistêmicos;
	- Potenciais agentes irritantes locais.
- Exame ginecológico:
	- Presença de prurido;
	- Consistência;
	- Cor;
	- Odor;
	- Irritação local.
- Testes diagnósticos:
	- Avaliação do pH vaginal;
		- Normal: levemente ácido <4,5.
	- Teste de KOH 10%;
	- Exame a fresco + SF 0,9%;
	- Baterioscopia com Gram.
	- Amostra cervicovaginal para cultura.
	- Amostra endocervical para biologia molecular.
