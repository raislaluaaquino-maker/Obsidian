# Etiologia
- Infecções de estruturas contíguas (otites, sinusites);
- Pós-TCE;
- Pós-neurocirurgia;
- Disseminação hematogênica;
- Pós-meningite;
- Comumente flora polimicrobiana (Streptococus Sp., S.Aureus;)
- Gram (-): Kleibsiella pneumonia, E.coli;
# Quadro Clínico
- Cefaleia;
- Febre;
- Déficits focais;
- Alterações do nível de consciência;
# Tratamento
- Vancomicina + Metronidazol + Cefalosporina de 3ª geração (meropenem ou cefepime, caso suspeita de pseudomonas);
- Cerebrais >2,5-3 → Tratamento cirúrgico associado;
- Empiemas → sempre associas tratamento cirúrgico;
